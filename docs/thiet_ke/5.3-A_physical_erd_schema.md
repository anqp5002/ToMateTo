## 2. Cách đọc mô hình

- PK định danh một dòng; FK buộc dòng tham chiếu tồn tại; UNIQUE chặn trùng; CHECK giới hạn giá trị.
- Quan hệ `||--o{`: một bản ghi cha có từ 0 đến nhiều bản ghi con, mỗi con bắt buộc có một cha.
- Quan hệ `|o--o{`: con có thể không còn cha, ví dụ báo cáo giữ lại khi bài gốc bị xóa.
- Nullability, điều kiện UNIQUE và ON DELETE chính xác nằm trong DOC 5.3-B. Sơ đồ chỉ hiển thị cột nhận diện và liên kết để dễ đọc.
- Dữ liệu quan hệ dùng FK; JSONB/ARRAY chỉ dành cho khối nội dung không cần FK đến từng phần tử. Bản nháp AI không phải bài đã đăng.
- Thiết kế gồm 25 bảng, bao gồm `user_blocks` để đọc dữ liệu chặn nạp sẵn theo REQ-028. Không bổ sung chức năng tạo block trong v1. Số bảng không đại diện cho số chức năng.

### 2.1 Tài khoản, phiên và ảnh

```mermaid
erDiagram
    users {
        bigint id PK
        text email_normalized UK
        int token_version
        text_array public_profile_fields
        uuid avatar_media_id FK,UK
        uuid cover_media_id FK,UK
    }
    password_resets {
        bigint id PK
        bigint user_id FK
        text otp_hash
        text reset_token_hash UK
    }
    revoked_tokens {
        uuid jti PK
        bigint user_id FK
        timestamptz expires_at
    }
    user_devices {
        bigint id PK
        bigint user_id FK
        text push_token UK
    }
    media_assets {
        uuid id PK
        bigint owner_id FK
        text purpose
        text state
        text provider
        text storage_key
    }
    media_cleanup_jobs {
        bigint id PK
        uuid media_id FK,UK
        timestamptz next_attempt_at
    }
    media_assets ||--o| media_cleanup_jobs : cleanup
    users ||--o{ password_resets : requests
    users ||--o{ revoked_tokens : revokes
    users ||--o{ user_devices : owns
    users ||--o{ media_assets : uploads
    media_assets |o--o| users : avatar
    media_assets |o--o| users : cover
```

Avatar và cover là hai FK tùy chọn, mỗi quan hệ tối đa một bản ghi ở mỗi phía. Mỗi FK UNIQUE khi khác NULL. Service kiểm purpose và chủ sở hữu, ngăn cùng asset dùng sai mục đích giữa các quan hệ. Khóa duy nhất của kho ảnh là cặp `(provider, storage_key)`, không phải riêng storage_key; quy định đầy đủ ở DOC 5.3-B.

### 2.3 Dữ liệu chặn nạp sẵn

```mermaid
erDiagram
    users {
        bigint id PK
    }
    user_blocks {
        bigint blocker_id PK,FK
        bigint blocked_id PK,FK
        timestamptz created_at
    }
    users ||--o{ user_blocks : blocker
    users ||--o{ user_blocks : blocked
```

Đây là dữ liệu đọc phục vụ REQ-028 và ghi chú CRUD số 7 trong FR trên main. Nguồn nạp là seed/fixture được team review; không có mutation tạo block. Quy tắc lọc đề xuất ở T25, cần BE/Lead xác nhận O6.

### 2.4 Trợ lý và snapshot xu hướng

```mermaid
erDiagram
    users { bigint id PK }
    posts { bigint id PK }
    dishes { bigint id PK }
    tags { bigint id PK }
    chat_sessions {
        bigint id PK
        bigint user_id FK
        jsonb context_json
    }
    chat_messages {
        bigint id PK
        bigint session_id FK
        bigint reply_to_id FK,UK
        bigint processing_version
        timestamptz processing_expires_at
        text role
        text status
        jsonb post_draft
    }
    trending_runs {
        bigint id PK
        timestamptz window_start
        timestamptz window_end
        timestamptz published_at
    }
    trending_post_snapshots {
        bigint run_id PK,FK
        bigint post_id PK,FK
        numeric score
    }
    trending_dish_snapshots {
        bigint run_id PK,FK
        bigint dish_id PK,FK
        numeric score
    }
    trending_tag_snapshots {
        bigint run_id PK,FK
        bigint tag_id PK,FK
        numeric score
    }
    users ||--o{ chat_sessions : owns
    chat_sessions ||--o{ chat_messages : contains
    chat_messages |o--o| chat_messages : replies_to
    trending_runs ||--o{ trending_post_snapshots : publishes
    trending_runs ||--o{ trending_dish_snapshots : publishes
    trending_runs ||--o{ trending_tag_snapshots : publishes
    posts ||--o{ trending_post_snapshots : ranked
    dishes ||--o{ trending_dish_snapshots : ranked
    tags ||--o{ trending_tag_snapshots : ranked
```

Ba bảng snapshot phân biệt bài hot, món và thẻ; không lấy tổng like mọi thời điểm để gọi là xu hướng 7 ngày. Snapshot chứa điểm theo một lần tính; thuật toán và trọng số do BE chốt ở S6. Khi đọc luôn kiểm lại bài còn hiển thị.
