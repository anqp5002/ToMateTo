## Luồng 1: Đăng bài (UC-05)

```mermaid
flowchart TB
  U1([User mở /compose]) --> U2[User nhập tên món + nội dung + chọn ảnh]
  U2 --> B1{BE: thiếu tên món?}
  B1 -- thiếu --> E1[BE: chặn + báo bắt buộc]
  B1 -- đủ --> B2[BE uploadImage qua Image Store]
  B2 -- lỗi ảnh --> B3[Vẫn cho đăng text, retry ảnh sau]
  B2 -- ok --> B4[BE createPost lưu Post + Media]
  B3 --> B4
  B4 --> F1[FE: đưa vào MyPosts + feed NEW]
```

* BR: tên món bắt buộc; ảnh lỗi không chặn đăng text. Bottleneck: upload ảnh mạng chậm.

## Luồng 2: Thích + thông báo (UC-07)

```mermaid
flowchart TB
  U1([User bấm Like/Save]) --> A1{Đã login?}
  A1 -- chưa --> L[Login trước rồi quay lại]
  L --> B1
  A1 -- rồi --> B1[BE toggleLike/savePost]
  B1 --> P1[Trả kết quả cho người bấm]
  B1 --> P2[Gửi notify cho chủ bài qua Push]
  P1 --> END([Xong])
  P2 --> N1[Chủ bài mở NotificationScreen]
```

* BR: like toggle 1 user/1 bài. Bottleneck: push lỗi không được chặn like.

## Luồng 3: Theo dõi (UC-08 — tách riêng theo WBS)

```mermaid
flowchart TB
  U1([User bấm Follow ở Profile]) --> B1[BE toggleFollow]
  B1 --> P1[Cập nhật trạng thái follow]
  B1 --> P2[Gửi notify cho người được follow]
  P1 --> END([Xong])
  P2 --> N1[Người đó mở NotificationScreen]
```

* BR: save không cần follow. Tách khỏi Luồng 2 để rõ theo WBS.

## Luồng 4: Báo cáo → ẩn bài (UC-09)

```mermaid
flowchart TB
  U1([User Report từ /post/:id]) --> B1[BE reportPost ghi Report + lý do]
  B1 --> B2{Đủ N report?}
  B2 -- chưa --> K1[Giữ bài + đếm chờ]
  B2 -- đủ --> B3[BE ẩn bài chờ duyệt + notify chủ bài]
```

* N chưa chốt ở S1, để S2. Bottleneck: report ảo → S2 chống spam.

## Luồng 5: Gợi ý AI → draft → đăng (UC-10/11)

```mermaid
flowchart TB
  U1([User mở chat]) --> B1[BE createChatSession]
  B1 --> U2[User gửi câu hỏi]
  U2 --> B2[BE gửi prompt qua Chatbot LLM]
  B2 -- lỗi/timeout --> E1[Báo lỗi + giữ lịch sử + cho gửi lại]
  B2 -- ok --> F1[Hiện gợi ý + lý do]
  F1 --> D1{Có postDraft?}
  D1 -- không --> U3[Hỏi tiếp hoặc thoát]
  D1 -- có --> B3[usePostDraft mở compose prefill]
  B3 --> U4[Sửa rồi đăng - sang Luồng 1]
```

* BR: gợi ý kèm lý do; không bắt cấp vị trí khi chỉ xem. Bottleneck: LLM timeout.
